# Codex Project Launcher v1.0.0

First stable release.

## Highlights

- Save and manage VS Code projects from one launcher.
- Launch each project with its own `CODEX_HOME`.
- Launch each project with its own VS Code `--user-data-dir`.
- Keep Codex conversation history isolated per project.
- Open multiple isolated project windows at the same time.
- Reuse existing Codex authentication/config without copying sessions.
- Search, rename, remove, refresh, and open project folders.
- Configure the VS Code executable and launcher data locations.
- Includes the application icon in the Windows executable and main window.

## Windows note

This release is currently unsigned, so Windows SmartScreen may show an **Unknown Publisher** warning. Code signing is planned separately.
